MANUAL DEL RECLUTA

Apuntá. Calculá. Dispará.

A D o ← → para moverte. W para saltar. Ratón o ↑ ↓ para apuntar. Regulá la potencia con Q / E (mantené para ajustar) o − / + (un punto). También podés usar el deslizador; después dispará con ESPACIO.

Tenés 45 segundos y movimiento limitado por turno. El mate bomba rebota; el naranjazo explota al impacto; el chumbo viaja más rápido. Gana el último equipo con carpinchos vivos.

En móvil, tocá el escenario para apuntar y usá los botones. Para jugar online estará disponible próximamente y requerirá una cuenta conectada a SaltoPlay.
